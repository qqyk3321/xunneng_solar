# Sol & Tide Energy：八位独立 AI 专家评审汇总

评审日期：2026-09-19。对象：公开首页、Antigua / Dominica 地区首页、FAQ、咨询入口与隐私说明。

## 怎样完成这次评审

使用密码学随机数生成8个互不相同的128字符十六进制字符串，分配给8个独立子agent作为角色标识，并显式指定不同专业关注点。随机串不是资历或专业能力证明。每位使用新会话、不继承之前评审，也不读取同伴记录；最多3位并行、分批完成。这是8个AI模拟视角，不是8位真人持证专家，也不代表统计独立抽样。

完整随机串、角色及评分规则见 [manifest.json](./manifest.json)。每份原始记录包含范围、方法、评分理由、证据、影响、优先级、修改与验收建议。主评审另做事实和算术复核，见 [root-verification.md](./root-verification.md)。

评的是网站能否支持客户理解、信任和采购尽调，不是公司的实际工程能力。没有公开证明不等于没有资质、没有客户或违法。没有测试受保护的 `/solar-analysis`，不得将首页简易计算器的问题套用到该高级工具。本次只新增评审文档，没有修改业务代码、提交客户资料、写库、发布或推送。

### 共识与差异

八份记录都指出了未核验安装数量/主体证据，以及隐私或责任说明缺口；地区FAQ冲突见专家02–08共七份记录。经济视角特别重视独立价格和收益依据，C项给3分；UX及内容视角更认可现有假设披露，C项给6分。它们不矛盾：已有解释值得保留，但不等于已有工程预测或真实成本报价。

客户理解E项均值7.0，高于证据A项4.0与责任/隐私F项4.25。这支持“先补信任与一致性，不先堆新功能”的修改方向。没有一份报告给出经验证的P0事故；这不等于已经完成安全、法律、后端或真实工程审计。

## 主评审结论

现有网站已经具备清楚的服务表达和可用的初步咨询路径。真正拖累采购信心的，不是缺少更多动画或营销文字，而是数字依据、地区内容一致性、可核验主体与履约责任之间还没有形成完整证据链。

应优先修复已证实的错配和不恰当的示例数据，再补业务证据与测算依据。重做全部页面不是本次证据支持的必要结论。

## 不能误报的地方

- **已有免责声明。** 80%假设、历史电价、非报价及设备认证不等于项目批准，在问号或FAQ已有说明；建议提高显著性和一致性，而不是说从未披露。
- **已有正常的手机交互。** 专家06实测390px无横向溢出，菜单、键盘滑块、FAQ搜索、地区切换、咨询首屏可用。没有完成全设备测试、提交链路或真实海岛网络性能测量。
- **Cookie选择确实会保存。** 专家01、06引用隐私政策的“不保存”是页面原文，不应当成实测事实。主评审实测浏览器localStorage保存偏好；未接入服务控制才是当前边界，政策本身需要更新。
- **2026年10月变价已提醒。** Dominica问号已经说明未包含新结构；截至本评审日尚未到生效日。不能据此直接判现价错误或编造新费率。[IRC公告](https://www.ircdominica.org/news/new-electricity-tariff-takes-effect-october-1-what-customers-should-know/)
- **审批不等于证书。** 当地申请/投运责任需要写清，但网页证据缺失不能证明任何已建项目无许可。[APUA流程](https://www.apua.ag/programs/green-antigua/renewable-energy-antigua/)、[IRC许可说明](https://www.ircdominica.org/news/call-for-mandatory-licensing-of-dreg-facilities/)
- **6kW逆变器不直接决定监管类别。** APUA公示的容量相关结算安排需要核实具体计量对象、系统模式和当前适用性，不据此直接断言首页套餐无法自用或不能接入。

## 后续实施边界

可以先做无需编造事实的修正：地区FAQ与链接、撤下未核验计数、结果假设显著化、Cookie说明一致性。业务方随后提供真实主体与联系方式、案例、成本依据、设备文件、安装/售后范围和隐私安排，再完善公开资料与报价模板。

保存完整原始记录是为了允许追溯、质疑和复评；不是让八个角色的相似判断替代真实客户访谈或当地专业审核。
